# 拾光 · 大学生日程

一个轻量、温暖的大学生日程管理平台，打开浏览器即可使用。

项目采用 MIT 许可证开源，任何人都可以自由使用、修改和分发。

## 功能

- 一周课表：录入课程名称、星期、时间、教室和老师
- 今日总览：自动展示当天课程与课程状态
- 待办事项：记录作业、考试、社团和生活安排
- 考试倒计时：自动计算最近考试剩余天数
- 本地保存：数据保存在浏览器中，不上传个人课表
- 响应式设计：支持电脑和手机

## 使用

直接打开 `dist/index.html`，或将 `dist` 目录部署为静态网站。

项目使用原生 HTML、CSS 和 JavaScript，无需安装依赖。

界面以 iPhone 15（393 × 852）为主要适配尺寸，同时兼容其他手机和电脑。页面不依赖境外字体、CDN 或第三方接口。
